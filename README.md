# ملایرنامه — راهنمای راه‌اندازی

## ساختار فایل‌ها
پوشه اصلی شامل index.html، پوشه css با فایل style.css، و پوشه pages با فایل services.html است.

## راه‌اندازی سریع (رایگان)
۱. یک حساب گیت‌هاب بساز (github.com)
۲. یک ریپازیتوری جدید بساز و همین فایل‌ها را در آن آپلود کن
۳. از تنظیمات ریپازیتوری، بخش Pages را فعال کن
۴. سایت روی آدرسی مثل username.github.io/malayer-nameh بالا می‌آید

## وصل کردن دامنه اختصاصی
بعد از خرید دامنه:
۱. در تنظیمات DNS دامنه، یک رکورد CNAME به آدرس گیت‌هاب‌پیجز اضافه کن
۲. در تنظیمات Pages گیت‌هاب، دامنه اختصاصی را وارد کن
